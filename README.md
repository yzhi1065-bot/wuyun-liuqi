# 五运六气排盘 · 独立版

> 基于年干支推演五运六气 — 中运、主客运、司天在泉、主客气及客主加临在线查询。

纯前端实现，无需后端，直接打开 HTML 即可使用。

## 功能

- 干支纪年 → 五运六气全套推算
- 中运（岁运）+ 五行属性
- 主运 / 客运 五步推演
- 司天 / 在泉 + 左右间气
- 主气 / 客气 六气分布
- 客主加临（气相得/不相得）
- 年份快速跳转（近 120 年）
- 深色主题，中式视觉风格

## 使用

**在线使用**：部署到 GitHub Pages 或任何静态服务器即可。

**本地使用**：直接在浏览器打开 `index.html`。

```
git clone https://github.com/yzhi1065-bot/wuyun-liuqi.git
cd wuyun-liuqi
# 直接用浏览器打开 index.html
```

无需安装任何依赖，零配置。

## 数据来源

推算逻辑基于《黄帝内经》五运六气理论体系。
